# Stage 03 exposure inventory (2026-10-29, before the final campaign)

This inventory is required by the owner's supplemental directive (section 6.1). It is generated by
`scripts/exposure_inventory.py` from committed files only; the output is `exposure_inventory.json`. "Exposed" is
read conservatively: any article group that was selected, captured, annotated, extracted, used in a fixture or a
demonstration, or named as development material. Material that existed only in the previous session's private
workspace is missing (`RECOVERY_NOTE.md`). That is not proof it never existed, so every group that previous session
could have touched is counted as exposed.
