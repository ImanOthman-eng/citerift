## 2. Answers to the brief's questions

1. **Order assumptions.** `_match_templates` and `_match_in_note` hold on the corpus (H-2): equal keys expand equally, so a swap between equal keys is harmless. Prose `_align` holds on the corpus (H-1). The nested `_align` is order-dependent (A-05). Multi-part transclusions break the one-template-one-about assumption (A-02, A-03). The two-pass `source_model` reconciles the same notes twice; this is deterministic and matched across seeds. `{{r}}`, `{{sfn}}`, `{{efn}}` and `{{#tag:ref}}` are grouped by the template that generates them. Each sfn call is anonymous and is its own top template, so they pair as `single_use`. Parser functions do appear as `template` parts with a `function` key, so they are read. The corpus has no `{{#tag:ref}}`. List-defined refs are not uses (`model.py:330-337`). Containers of same-name swaps are not affected: all markers of one name point to one note, so `_containers` and the marker observations do not change. Only the marker loci in G6 change.
2. **R-038 correction.** On its own the role evidence is sound: data-mw `body` agrees with the source `has_body` for every pairing in the corpus (`survey_corpus.out`, table by basis; 0 disagreements). The anchors are sound for NBSP, thin space, `<br>`, link trails, piped links, Arabic, the Arabic comma, nested inline markup and `data-sort-value` (`anchors_battery.out`). Some cases give no support: a `display:none` sort key written in the source, a class hidden only by TemplateStyles, a case change, a template that turns digits into Arabic-Indic, formatnum, and named-argument values with digits (`{{val|5|ul=m2}}`). Each of these is conservative on its own, but each lets the true marker fall out of a non-empty support, and that is exactly what A-01 exploits. The boundary rule ignores the sign: `1.31` supports `−1.31`, and `{{val|-5}}` and `{{val|5}}` support each other. This only matters through A-01. `_settle` is sound only if every non-empty support contains the true marker; A-01 shows a counterexample, and the partial rule (`:502-507`) has the same weakness. Bounds work as stated. Cost: A-06. Determinism: canonical outputs are byte-identical under `PYTHONHASHSEED` 0, 1 and 987654 for six R-038-relevant bundles (`determinism.out`). The element-set fix in `preceding_text` is stable.
3. **Accounting.** Every source use ends `matched`, `abstained` or `source_only`; extract's checks enforce this. No render use is matched twice in the corpus. When it does happen (A-02, S2b), the one-to-one check turns it into `BUNDLE_SEMANTIC_INVALID`, so it is loud rather than silent. Abstained uses never give a container on their own; a container needs a matched use. The issue lists are stale for `source_only` uses (A-07). Doubtful regions give `not_inspected`.
4. **Coverage.** The correction's own abstentions are small: 2 uses (HESA data templates), as the DESIGN says. The dominant abstention in the subsystem is A-02 (55 of 107 corpus abstentions; 81 en and 26 ar in total, `survey_abstentions.out`). Among the labelled links, 69 are "engine abstained, label has marker"; the A-02 prototype recovers 11 of them correctly with 0 new false attachments. In the ar G6c denominator, ar-76814232 alone goes from 9/21 to 17/21 linked labelled uses.

## 4. Verdict

High-severity defects remain at 10bf0d2:

On section 7 of the directive, the readiness gate is not met until A-01 and A-03 are fixed, with A-02 strongly advised.
